# Care Connect — Reference Pack

This ZIP contains:
- `reference_images/`: the available colourful Neo-Brutalist reference images with bold black icons/outlines.
- `Care_Connect_Implementation_Plan.json`: a from-scratch implementation brief for an Android-first Care Connect app.

## Important
The PNGs are visual references, not a completed application. The JSON is an implementation plan, not generated source code. The earlier teal/blue dashboard and earlier clean-modern collage concepts were excluded because they do not match the currently approved Neo-Brutalist direction. The medicine reminder and other not-yet-generated screens are specified in the JSON but are not represented as finished reference images.

## Start
Give the JSON and the `reference_images` folder to your coding agent together. Ask it to inspect the images and implement the project in phases, testing each phase. Do not paste API keys or credentials into source code or commit them to Git.
